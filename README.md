# COMP517 Practice Test

A timed class-test simulator for COMP517 Programming Fundamentals (University of Liverpool). Three practice papers, each with three Python questions and a 40-minute timer. **Run** shows your output only; **Hand in** saves a version; at the end your handed-in code is marked against hidden tests (out of 99), with the model answers.

**Open it:** https://moayidalsubhi.github.io/comp517-practice/

- Python runs in your browser ([Brython](https://brython.info)), so nothing needs installing. The first load takes a few seconds.
- Drafts and scores are saved only in your own browser.
- Unofficial practice material. It isn't affiliated with the module team or the grading platform used in the real test.
